05 · Route Optimization

Optimal Route Planner

TSP Next.js Kakao Maps Firebase

여러 장소를 최소 시간으로 도는 순서를 찾는 TSP. 카카오 모빌리티의 방향성 거리(A→B ≠ B→A)를 그대로 반영한 비대칭 거리 행렬 + Branch and Bound 모바일 웹. 11 지점(9 경유) 기준 naive 362,880 호출을 111 호출로 줄여 99.969% 절감.

자세히 →

공통 설계 원칙

  • 업무 흐름에서 출발 — 모두 현장에서 반복되던 수작업(날짜 계산·기록·조건 확인)을 자동화한 결과다.
  • 외부 ML 라이브러리 없음 — how-many-blood의 단변량 OLS, red-toolkit의 Ridge closed-form 모두 순수 JS. 번들 사이즈·런타임 무관, 브라우저에서 즉시 동작.
  • 예측은 설명 가능하게 — 결과 객체에 계수·팩터·신뢰도를 함께 담아 "왜 이 값이 나왔는가"를 직원이 이해할 수 있게 했다.
  • 서버리스 우선 — Firebase Functions + Firestore / Supabase. 인프라 운영 비용 없이 스케줄·인증·실시간 DB를 쓴다.

데이터 비공개. 이 도구들은 사내 업무용으로, 실제 운영 데이터는 공개하지 않는다. 포트폴리오의 모든 화면은 mock 데이터로 검증했으며, 실제 수치·자격증명은 사용하지 않았다.
