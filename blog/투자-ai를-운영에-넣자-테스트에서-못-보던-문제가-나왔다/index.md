# 투자 AI를 운영에 넣자 테스트에서 못 보던 문제가 나왔다

과거 차트로 모델을 학습시키고, 하나의 모델을 여러 모의 트레이더가 공유하는 실험을 이번에는 상시 서비스로 옮겼다. 코드를 작성하고 테스트를 통과하는 것과 실제로 계속 돌아가는 것은 다른 일이었다.

금융투자부는 Laya의 공통 scorer를 학습한다. balanced, momentum, defensive 세 트레이더는 그 모델을 공유하면서 각자의 정책과 원장으로 모의운용한다. 추론, 학습과 관측 정산, 시세 평가와 위험 관리는 별도 로컬 프로세스다. 이 세 프로세스는 클라우드 에이전트의 토큰 잔량을 필요로 하지 않는다.

첫 설치는 매끄럽지 않았다. macOS의 Background 서비스로 실행한 추론이 두 번 45초 제한을 넘었다. 실행 분류를 Standard로 바꾼 뒤에는 같은 모델이 약 25초에 추론을 끝냈다. 최초 학습도 데이터셋과 계획을 만든 뒤 완료 기록 없이 프로세스가 사라졌다. 학습을 별도 프로세스 그룹으로 분리하고, 부모가 종료돼도 끝까지 실행되는지 확인했다. 중단된 시도의 파일과 로그는 보존하고 동일한 데이터·부모 모델·학습 조건으로 그 작업을 이어 실행했다.

또 하나는 실행 파일 밖의 의존성이었다. 일부 서비스는 파일 열기에서 멈췄지만 같은 배포물을 직접 실행하면 성공했다. 운영에 필요한 금융 설정을 검증된 원문 그대로 배포물 안에 담고 원본과 복사본의 해시를 확인했다. 개발 폴더 접근 없이 동작하도록 바꾼 뒤 상태 갱신을 확인했다. macOS 내부의 정확한 정지 원인을 확인한 것처럼 쓰지는 않겠다.

재시작 순서도 보완했다. 추론 결과가 아직 준비되지 않았다는 이유로 거래자를 바로 영구 정지시키지 않도록, 시작 후 최대 60초 동안 새 패킷을 기다린다. 그동안 새 전략 체결과 일봉 소비를 멈추되 시세 평가와 자본 하드스톱은 계속한다. 손상된 모델이나 잘못된 패킷에는 이 유예를 적용하지 않는다.

복구 후 과거 데이터 학습은 실제로 완료됐다. 같은 부모 모델의 검증 손실은 0.679111에서 0.679062로 낮아졌다. 이것은 재사용한 과거 데이터에서 얻은 작은 개발 지표 개선이다. 미노출 성과 검증을 통과했다거나 수익을 낼 수 있다는 뜻은 아니다. 수익성 평가의 기각 기록도 그대로 남겼다.

세 모의 원장은 각각 가상 10만 원으로 시작했고, 이번 설치 과정에서는 체결이 없었다. 실제 자금을 넣거나 실제 주문을 보내는 경로는 없다. 새로운 결과가 쌓이면 현금 유지, 실패, 손실까지 함께 기록할 예정이다.

FARM 2.2.57의 main 반입과 영구 서비스 설치를 마쳤다. Bun 테스트 725개, 기존 Python 테스트 24개, 실제 MiniMax의 커밋별 독립 검토를 확인했다. 서비스는 사용자 로그인 후 자동 시작하고 종료 시 재시작한다. 이 Mac이 잠들거나 로그아웃하면 계속 실행되는 서버는 아니므로, 무중단 서버 운영과는 구별해야 한다.

이제 금융투자부의 일은 현재 시장에 말로 지시하는 데서, 과거 데이터로 자식 모델을 훈련하고 새 예측과 실제 모의운용 결과를 비교하는 일로 옮겨가고 있다. 결과가 좋았다는 결론보다, 학습과 실행이 실제로 이어지고 실패를 숨기지 않는 구조를 먼저 확인하고 있다.
